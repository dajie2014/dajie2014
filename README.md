## 我做东西的三条规矩

1. **把坑写下来。** 每个项目都带一份踩坑清单
   （[示例](https://github.com/dajie2014/dictation-turbo/blob/main/PITFALLS.md)）：症状、为什么、怎么绕 ——
   让下一个人不用重走一遍。
2. **给 AI 也留一份说明书。** 安装指令可以整段丢给 agent，每一步都写了"怎么确认这一步真的成了"。
3. **不假装成功。** 测试没过就写没过，做不到的事说做不到。

## What I'm building

**Dictation Turbo** — double-tap Control anywhere on a Mac, speak, and the text lands at your cursor.
No input-method switching; Chinese, German, English, French, Italian, Spanish, Russian — 20+ languages.

### [⬇ Download the latest release](https://github.com/dajie2014/dictation-turbo/releases/latest) (Mac, Apple silicon)

| Project | What it is | Requirements |
|---|---|---|
| [dictation-turbo](https://github.com/dajie2014/dictation-turbo) | System-wide: lives in the menu bar, works in any app | Needs [VoiceStudio](https://github.com/debpalash/VoiceStudio) as the speech engine (**free, open source**) |
| [dsh-dictation-turbo](https://github.com/dajie2014/dsh-dictation-turbo) | In-window plugin for DeepSeek Harness | Chinese and English need nothing else; German adds VoiceStudio (**also free**) |

> **Everything you install here is free.** VoiceStudio is free, open-source software
> (AGPL-3.0) — nothing to buy, no subscription; both projects are MIT.
> **There is nothing to purchase.**

## Three rules I build by

1. **Write down every pitfall.** Every project ships with a list of the ones I hit
   ([example](https://github.com/dajie2014/dictation-turbo/blob/main/PITFALLS.md)): the symptom, why it
   happened, and how to get around it — so the next person doesn't have to find out the hard way.
2. **Ship an agent-ready manual.** The install instructions can be handed to an AI agent as-is, and
   every step says how to check that the step actually worked.
3. **Never pretend it worked.** If a test fails, it says so. If something isn't possible, it says so.
